# Same Page — a shared puppy logbook

A phone-first web app for two households keeping one record of the same puppy:
meals, potty, crate and alone-time training, naps, teething, commands, symptoms.
Targets are scaled to her age and size, so a four-month-old toy-breed gets a
three-hour potty window rather than the usual "one hour per month".

Installs to the iPhone home screen. No App Store, no Apple fee.

## Stack

- One static page, no build step. `public/index.html` is the whole app.
- Supabase for auth, Postgres and realtime (project `same-page-puppy-log`).
- Vercel for hosting.

## Launching

Two steps, both need your own login.

### 1. Turn off email confirmation (30 seconds)

Supabase dashboard → **Authentication** → **Sign In / Providers** → **Email** →
turn **Confirm email** off, and save.

Without this, a new account has to click a link in an email before it works, and
Supabase's built-in mail server only sends a couple of messages an hour on the
free plan. With it off, sign-up is instant.

### 2. Deploy

```
cd ~/puppy-logbook
npx vercel login
npx vercel --prod
```

Accept the defaults; when it asks which directory to deploy, the answer is the
repo root — `vercel.json` already points at `public`. It prints the live URL.

## Getting both households on one logbook

1. You open the URL, create an account, choose **Start a new household**.
2. Settings (the gear, top right) shows an **invite code**. Copy it.
3. Your sister opens the same URL, creates her own account, chooses
   **Join with a code**, pastes it.

From then on you are writing to the same record and each other's entries appear
live. Every row is guarded by row-level security keyed on household membership,
so nobody outside it can read or write anything.

## Adding it to the home screen (iPhone)

Open the URL in Safari → Share → **Add to Home Screen**. It gets the paw icon and
opens full-screen with no browser chrome. Dark mode follows the phone, and
Settings has an override plus five colour palettes.

Do this on both phones. Safari is required for the install — Chrome on iOS
cannot add to the home screen.

## Layout

```
public/index.html          the entire app: markup, styles, logic
public/config.js           Supabase URL + publishable key (safe to ship)
public/sw.js               service worker; caches the shell so it opens offline
public/manifest.webmanifest
public/icon-*.png          generated by scripts/make-icons.mjs
schema.sql                 the database, as applied
scripts/make-icons.mjs     regenerates the icons; no image dependencies
```

The publishable key in `config.js` is meant to be public — it grants nothing on
its own, because every table is behind row-level security.

## Local development

```
python3 -m http.server 4173 --directory public
```

Then open http://localhost:4173. It talks to the same live Supabase project, so
anything you log locally is real.
